# 浏览器端到端测试

对着**活的**服务跑真 Chrome（Playwright），验的是"用户实际看到的那个页面"，
不是接口返回什么。README 里"真浏览器端到端 10 个脚本"指的就是这里。

## 一键跑

```bash
xvfb-run -a ./run-all.sh --host 127.0.0.1 --port 18088 --token <访问令牌>
```

判据只有两个：**每个脚本的退出码**，以及输出里有没有 `✗`。
不看任何一行"看起来还行"的汇总 —— 这一套曾经在**页面 401** 的情况下报 8/9。

令牌取法（按优先级）：`--token` → 环境变量 `RC_TOKEN` → 从设备上的
`/data/misc/remote-control/remote-control.conf` 读（需要 adb root，
设备用 `RC_SERIAL` 指定）。交付镜像默认开鉴权，**没有令牌时大多数检查
照样会"通过"**（拖动条范围、元素存在性这些是纯 UI 的），所以令牌这一环
必须给上，否则跑出来的绿是假的。

## 十个脚本

| 脚本 | 验什么 |
|---|---|
| `coord_space_test.py` | 点画布正中央 → uinput 收到的 ABS 值就是范围的一半 |
| `filebrowser_test.py` | 文件浏览：进目录、新建、删除、越界路径被拒 |
| `fillmode_test.py` | 铺满/适应两种缩放模式 |
| `maxwidth_test.py` | `maxWidth` 降采样 |
| `mouse_test.py` | 鼠标注入与滚轮 |
| `rotate_test.py` | 转屏后画布与**触控坐标空间**同步 |
| `text_test.py` | 控制台文字输入（含中文） |
| `upload_test.py` | 上传：小 APK 走完整链路，300 MB 验上传被接受 |
| `webui_test.py` | 控制台整体：画质拖动条、格式切换、抓帧行 |
| `webui_stream_test.py` | 画面流与 WebCodecs（H.264） |

## 踩过的坑（都记在各自脚本里）

* **假绿**：没令牌时页面每个 API 都 401，而多数检查仍然通过 —— 看起来
  "9 项挂 1 项"，其实是整套在对着一个连不上的页面跑。
* **永远不可能通过的断言**：有一条检查断言文本里有"服务端"三个字，
  而那三个字**只出现在 HTML 注释里**，从来没进过渲染结果。
* **脆阈值**：一条要求比值 > 1.5，实测 1.46 —— 产品没问题，是断言太脆。
* **场景过期**：`webui_stream_test` 里"保存令牌重建流"那段是把令牌框
  **清空**再保存，那是在没开鉴权的年代写的；开鉴权后必然 401 超时。
  产品的行为是对的，是测试的动作错了。
* **素材不在仓库里**：`upload_test` 的大文件素材原本手搓到 `/tmp/mid.apk`，
  换台机器就崩在准备步骤上。现在没有就现生成。
